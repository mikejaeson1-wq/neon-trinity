# Neon Trinity Studio 1.3.1

Dieses Update senkt den Datenverkehr der gemeinsamen Mediathek und der Hörräume.

- Das Studio merkt sich den zuletzt geladenen Katalog für das angemeldete Bandkonto. Bei unverändertem Stand genügt eine Abfrage der Versionsnummer, auch nach einem Neustart.
- Änderungen aus der Band kommen weiterhin über die Echtzeitverbindung an. Zusätzlich gleicht das Studio alle 30 Sekunden ab. Gleichzeitige Abfragen teilen sich eine Anfrage.
- Beim Abspielen in einem Hörraum prüft der Gastgeber den aktuellen Titel anhand seiner ID. Gäste, TV-Player und die angemeldete mobile Mediathek können einen bereits geladenen Katalog wiederverwenden.

Installiere das Update im Studio unter **Einstellungen → Studio & Updates → Nach Updates suchen** oder führe das Windows-Setup über der vorhandenen Installation aus. Deine lokalen MP3s, Band- und Event-Musik sowie bestehende Musikbox-Links kannst du weiterverwenden.
