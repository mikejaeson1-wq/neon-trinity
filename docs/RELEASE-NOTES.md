# Neon Trinity Studio 1.3.0

**Event Musik** ist eure eigene gemeinsame Sammlung für Beachclub, Feiern und andere RP-Events.

- Eigener Menüpunkt neben der Band-Mediathek.
- MP3s auswählen oder direkt in den Event-Bereich ziehen, bis 48 MiB pro Datei.
- Titel, Interpret, Genre und Cover bearbeiten; vorhandene MP3-Metadaten können beim Import übernommen werden.
- Einzelne Titel oder die ganze angezeigte Sammlung im Studio abspielen und nach Titel, Interpret oder Genre suchen.
- Über **Musikbox-Link** oder das Rechtsklick-Menü eine direkte MP3-URL erstellen und kopieren. Eine unveränderte Audiodatei verwendet denselben Link erneut.
- Die Event-Sammlung wird zwischen den freigeschalteten Studio-Konten abgeglichen. Sie gehört nicht zu den Band-Alben oder den privaten lokalen Songs.
- Event-Musik ist in den vollständigen Sicherungen und im Wiederherstellungsverlauf enthalten. Geteilte Musikbox-Dateien können separat über das Rechtsklick-Menü entfernt werden.

Vorhandene Band-Songs, private lokale MP3s, Playlists, Konten und Musikbox-Links werden beibehalten. Für das Update ist kein erneuter Import erforderlich.

Aktualisieren: **Einstellungen → Studio & Updates → Nach Updates suchen** oder das neue Setup über die vorhandene Installation installieren. Nicht vorher deinstallieren.
