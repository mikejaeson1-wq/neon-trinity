# Neon Trinity auf Fire TV

Der TV-Player ist zum Musikhören gedacht: Band-Songs, Alben, Warteschlange und gezielt an dein Konto freigegebene MP3s. Die persönliche lokale PC-Mediathek wird nicht automatisch übertragen.

## Über den Browser

Auf einem kompatiblen Fire TV im Silk-Browser diese Adresse öffnen:

https://mikejaeson1-wq.github.io/neon-trinity/tv.html

„Mit Handy verbinden“ wählen, den QR-Code mit dem Handy scannen, über Discord anmelden und das TV-Gerät ausdrücklich freigeben. Danach erscheinen die für dein Konto zugänglichen Songs auf dem Fernseher. Die QR-Anmeldung ist fünf Minuten gültig; ein bestätigter Gerätezugang gilt maximal 30 Tage.

## Als Fire-OS-App

Die Datei **Neon-Trinity-TV.apk** liegt beim Studio-Release unter Assets. Sie ist für Fire-OS-Geräte mit Android-API 23 oder neuer gebaut. Die Installation einer eigenen APK muss auf dem Gerät für den verwendeten Installer erlaubt sein. Die App erscheint als **Neon Trinity TV** und öffnet denselben TV-Player.

**Vega OS verwendet keine Android-APKs.** Auf diesen Geräten die kompatible Browser-/Webansicht verwenden. Ob Silk auf dem konkreten Modell verfügbar ist, muss dort geprüft werden. Diese Ausgabe enthält keine native Vega-App und wurde nicht auf einem physischen Fire-TV-Stick getestet.

## Bedienung

- Mit den Richtungstasten zwischen Schaltflächen und Songs wechseln; OK wählt aus.
- Die Medien-Tasten steuern Play/Pause und Vorheriger/Nächster.
- Repeat schaltet Aus → Playlist → einzelner Song → Aus.
- „Abmelden“ entfernt den Gerätezugang. Auf einem gemeinsam benutzten Fernseher anschließend abmelden.
- „Spotify öffnen“ startet in der Fire-OS-App die installierte offizielle Spotify-TV-App. Dort das eigene Konto verwenden und den Fernseher über Spotify Connect auswählen. Spotify-Musik läuft nicht eingebettet im Neon-Trinity-TV-Webplayer.

Eine bestehende Songfreigabe kann ihr Besitzer jederzeit entziehen. Bereits geladene Audiodaten lassen sich nicht nachträglich zurückholen. Bei laufender Verbindung gleicht der TV-Player seine Berechtigungen regelmäßig ab.
