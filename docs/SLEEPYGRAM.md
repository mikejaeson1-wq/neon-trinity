# Sleepygram mit dem Studio verbinden

Sleepygram: https://sleepygram.mikebamlee.chatgpt.site

Discord-Vorschaulink: https://neon-trinity-music.mikebamlee.chatgpt.site/sleepygram

Dex, Nix und Jax melden sich wie bisher mit Discord im Studio an. Die Teilen-Funktion verwendet genau dieses Konto. Sie stellt nie den persönlichen Bot-Zugang oder den internen Website-Zugang in der App bereit.

Rechtsklick auf einen Song → **Auf Sleepygram teilen**. Eigene lokale Songs und Band-Songs können als Song oder Cover geteilt werden. Bei Alben kann das Cover geteilt oder eine eigene Datei ausgewählt werden. Der vollständige Album-Export bleibt bei den bisherigen Hörlink-Funktionen.

Ein Entwurf bleibt sieben Tage im eigenen Sleepygram-Konto. Der Link öffnet den normalen Anmeldeweg und ist für andere Konten nicht lesbar. Direktes Posten erfolgt erst über die ausdrücklich beschriftete Schaltfläche. Der Dialog verändert keine Originaldateien im Studio.
