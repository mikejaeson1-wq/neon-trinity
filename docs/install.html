↓ Studio für Windows installieren

Windows 10 / 11 · 64 Bit · Immer die aktuelle veröffentlichte Version

01

Setup öffnen.

Lade die Setup-Datei herunter und öffne sie. Das Studio wird für dein Windows-Konto installiert und bekommt einen Eintrag im Startmenü.

02

Discord verbinden.

Öffne „Team & Discord“ und melde dich mit deinem freigeschalteten Discord-Konto an. Nix und Jax sind bereits für das Bandstudio hinterlegt.

03

Loslegen.

Eure gemeinsame Musik und Alben werden automatisch geladen. Persönliches Design und Hintergrund kannst du in den Einstellungen wählen.

DAS STUDIO BLEIBT AKTUELL.

Neue Versionen kommen direkt zu dir.

Das Studio sucht beim Start automatisch nach Updates. Unter „Einstellungen → Studio & Updates“ kannst du auch selbst nachsehen. Klicke auf „Update herunterladen“ und anschließend auf „Neustarten & installieren“.

Deine Anmeldung, Musik und Einstellungen bleiben erhalten. Wer bisher die ZIP-Version verwendet, installiert die Setup-Version einmal auf demselben Windows-Konto.

Windows zeigt einen Hinweis zum unbekannten Herausgeber?

Diese Ausgabe ist noch nicht digital signiert. Prüfe, dass du die Datei aus dem Repository mikejaeson1-wq/neon-trinity heruntergeladen hast. Falls Windows SmartScreen erscheint und die Datei aus dieser Quelle stammt: „Weitere Informationen → Trotzdem ausführen“.
